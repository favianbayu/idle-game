# 60. Sistem Upgrade

Semua upgrade **terlihat berubah di dunia** (model voxel diganti) dan memberi efek angka. Upgrade dibeli di tempat terkait
dan butuh waktu pengerjaan (dihitung hari game). Diskon dari hubungan: Uti (motor), Mas Fajar (semua kendaraan), Tegar
(kamar & warkop level akhir), Mei (buku), Gilang (bahan warkop).

Helm: half-face Rp 75.000, full-face Rp 250.000 (mengurangi pingsan saat kecelakaan 50%), helm custom Kirana (event).
